# Anpassa master-CV:t till en jobbannons

Utgå alltid från fakta i `data/profile-source-of-truth.json`. Lägg aldrig till en
teknik, roll eller prestation enbart för att den nämns i annonsen.

## Arbetsgång

1. Läs hela jobbannonsen.
2. Markera återkommande ord för roll, teknik och arbetsuppgifter.
3. Dela kraven i **obligatoriska** och **meriterande**.
4. Jämför varje krav med den verifierade profilen.
5. Använd arbetsgivarens exakta benämning när den stämmer med verklig erfarenhet.
6. Flytta de mest relevanta färdigheterna högst i kompetensavsnittet.
7. Prioritera de projekt som bäst visar att kraven är uppfyllda.
8. Skriv om sammanfattningen för den aktuella rollen och arbetsgivaren.
9. Ta bort mindre relevant innehåll om CV:t blir längre än två sidor.
10. Kontrollera att svensk och engelsk version beskriver samma fakta.

Undvik dolda sökord, upprepade nyckelord och långa listor utan stöd i projekt.

## Fyra möjliga inriktningar

### Software / Backend

Prioritera Python, FastAPI, REST API, MySQL, JavaScript, Git och Aurora Grand
Hotels. Lyft autentisering, bokningslogik och serverbaserad prisberäkning.

### Networking

Prioritera TCP/IP, Cisco Networking, ns-3, C++, Linux, TCP Cubic/NewReno och
VPN-trafikklassificeringen.

### AI / Machine Learning

Prioritera Python, pandas, NumPy, scikit-learn, klassificering, preprocessing,
utvärdering och TAM400-laborationerna. Använd endast verifierade modellresultat.

### Embedded Software

Prioritera C/C++, ESP32-C6, GPIO, I2C, interrupts och sensorintegration. Beskriv
serial-bus-projektet som pågående tills implementeringen kan verifieras.

## Kontroll före ansökan

- Kontaktuppgifterna är aktuella.
- Rollen och företagsnamnet är rätt i personliga brevet.
- Sammanfattningen matchar tjänsten.
- De viktigaste kraven syns i färdigheter eller verifierade projekt.
- Alla länkar fungerar.
- PDF-text kan markeras och kopieras i logisk ordning.
- Inga påståenden saknar stöd i källkod, notebook eller dokument.
